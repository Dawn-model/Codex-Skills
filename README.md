## 🟡简介
### ① 数学建模｜`math-model`

面向数学建模竞赛与综合建模任务，覆盖**问题分析、数据处理、模型建立、模型求解、实验验证和结果整理**等环节。强调先通过代码完成实验与验证，再根据实际结果进行模型分析和论文撰写，适合数学建模竞赛、科研建模及需要完整建模流程的任务。

### ② 路线规划｜`roadmap`

面向学习、科研和职业发展路线规划。根据目标、基础、时间和现实约束，制定**分阶段学习路线、技能体系、里程碑、时间安排和阶段性任务**，帮助将长期目标拆解为可执行的具体计划。

## 🔴安装方法
### 方法一：自动安装

将 `.zip` 压缩包直接上传到 Codex，然后发送以下提示词：

```text
请安装这个Skill，按照 Codex Skills 的标准目录结构安装，不要修改 Skill 内部文件。
确保每个 Skill 的 SKILL.md 都直接位于对应 Skill 文件夹的第一层，不要多嵌套一层。
```

### 方法二：手动安装

解压 `.zip` 压缩包后，将解压后的文件夹分别复制到 Codex 的 Skills 目录。
对应的路径为：
```text
~\.codex\skills\
```
可以在codex左侧栏的插件选项中，任意选择一个skill打开，点击右上角的更多，选择文件资源管理器打开，这样可以找到skill的安装目录。
安装完成后重启 Codex，在 Skills 列表中可以找到。
